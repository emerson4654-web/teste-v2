ATUALIZAÇÃO DO NOME PARA EXÉRCITO BRASILEIRO EMERSON

Este pacote contém somente os dois arquivos HTML alterados para atualizar o nome apresentado no site e na prévia de compartilhamento do Discord.

1. No GitHub, substitua index.html e dashboard.html pelos arquivos deste pacote.
2. Faça commit e aguarde o deploy no Render.
3. Para que o Discord atualize a prévia, envie a URL novamente com um parâmetro novo, por exemplo: https://SEU-DOMINIO/?v=emerson1

O domínio/canonical atual foi mantido como estava. Se quiser trocar o endereço do site também, ele deve ser alterado separadamente.
