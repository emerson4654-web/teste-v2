EB MANAGER — PACOTE CORRIGIDO
================================

Este ZIP tem os arquivos de código atualizados na RAIZ, sem subpastas. Não apague imagens que já existem no seu repositório. Faça uma cópia do repositório e dos dados antes de substituir arquivos.

ARQUIVOS PRINCIPAIS
- server.js: servidor, verificação da bio, sessão, API de CDP, promoções, histórico, ranking, permissões de CDE/divisões e solicitações de entrada.
- index.html: tela de login Roblox por código na bio.
- dashboard.html: painel visual, Sair, CDP, Entregar Patente, Hierarquia, Ranking, Histórico de Patentes, Promoção por Divisões e Painel CDE.
- package.json: comando de inicialização do Node.
- cargos_eb.json: grupo EB, cargos, sequência configurada, cargos que não podem receber promoção e salto das patentes da Presidência.
- divisoes.json: IDs dos grupos/cargos BFE, BPE, BAC, CIE, CIGS e BIP, promotores permitidos e limite do CDE por divisão.
- Arquivos de dados existentes (cdp.json, treinamentos.json, promocoes.json, historico-divisoes.json, promocao-cooldown.json, sessoes.json): ficam fora deste ZIP para não sobrescrever seus registros. Mantenha os que já existem. Se algum não existir, o servidor usa valores vazios e cria o arquivo ao primeiro registro.
- CDP_Roblox_Server.lua: Script para ServerScriptService que mostra as horas/status em um TextLabel e pode registrar treinamento quando um script confiável do servidor o informar.

RENDER (usar Web Service, NÃO Static Site)
- Build Command: npm install
- Start Command: npm start
- Root Directory: deixar vazio quando os arquivos estão na raiz.

Variáveis de ambiente necessárias/recomendadas:
EB_GROUP_ID=13616747
ROBLOX_OPEN_CLOUD_API_KEY=CHAVE_PRIVADA_OPEN_CLOUD
ROBLOX_CDP_API_KEY=UMA_CHAVE_SECRETA_LONGA_CRIADA_POR_VOCE
EB_PROMOTER_ROLE_IDS=IDs_SEPARADOS_POR_VIRGULA
EB_DATA_DIR=/var/data  (somente se você montar um disco persistente no Render em /var/data)

IMPORTANTE SOBRE PERMISSÕES
1) ROBLOX_OPEN_CLOUD_API_KEY precisa ter group:read e group:write e acesso aos grupos EB e divisões que o serviço vai operar. O usuário que criou a chave também precisa ter autoridade no grupo para atribuir os cargos desejados. Consulte https://create.roblox.com/docs/cloud/reference/features/groups e https://create.roblox.com/docs/cloud/reference/scopes.
2) O ID do grupo principal é 13616747. CDE é autorizado pelo cargo roleId 908892004 dentro desse grupo.
3) Entregar Patente no grupo principal usa EB_PROMOTER_ROLE_IDS (roleIds autorizados no grupo EB). Esse valor fica vazio por padrão de segurança porque o usuário ainda não especificou quais cargos do grupo principal podem executar promoções. Até preenchê-lo, o módulo principal mostra acesso restrito.
4) Promoção por Divisões é autorizada pelos roleIds configurados em divisoes.json: apenas os cargos de Subcomandante até Criador, conforme os dados enviados para cada divisão. CDE pode atribuir cargos no painel CDE até o limite de cada divisão; no BIP, que não possui cargo com o nome Dono na lista enviada, o limite configurado é [SUP-G] Paraquedista Supervisor-Geral.
5) O JSON original enviado pelo usuário contém rank=1 em quase todos os cargos. Por isso, as sequências de promoção das divisões foram configuradas seguindo a ordem da lista fornecida, NÃO por comparação dos ranks. Confirme a ordem real de cada divisão antes de permitir promoção real.
6) As promoções principais pulam Vice Presidente (842498073) e Presidente (845218008). Quem já está nos cargos bloqueados de Marechal até DEVELOPES (incluindo Elite Militar/Secreta/Real, Sub Comandante, Comandante e cargos administrativos listados) não pode receber nova promoção. O status Em CDP bloqueia promoção; a promoção principal também exige as horas da tabela correspondentes à patente atual.
7) O intervalo global de 30 minutos vale para promoções principais, por divisão e atribuição de cargos pelo CDE. O intervalo é persistido em promocao-cooldown.json.
8) Textos não têm atributo maxlength no formulário. O servidor ainda tem limites técnicos de tamanho de requisição e de foto para evitar abuso; textos nunca são truncados silenciosamente.

CDP NO ROBLOX STUDIO
1) No Studio, abra Game Settings > Security e habilite Allow HTTP Requests.
2) Coloque o conteúdo de CDP_Roblox_Server.lua num Script em ServerScriptService. NÃO use LocalScript.
3) No Script, troque EB_MANAGER_URL pelo endereço HTTPS do Web Service no Render (sem barra final) e CDP_API_KEY pela mesma chave definida em ROBLOX_CDP_API_KEY no Render.
4) O TextLabel consulta /api/roblox/cdp a cada 60 segundos e mostra as horas creditadas, as exigidas para a patente e o status Em CDP.
5) Para registrar um treinamento real a partir de um script confiável do servidor, depois de verificar a conclusão do treino, chame:
   game:GetService("ServerScriptService").EBRegistrarTreinamento:Fire(player, "Nome do treinamento", "Observações")
   O evento só existe no servidor. Não exponha a chave em LocalScript nem a envie para clientes.
6) A API registra treinamentos no ranking; ela NÃO converte automaticamente um treinamento em horas de CDP. As horas de CDP são creditadas no painel, na área Registrar horas de CDP.

DADOS E TESTES
- O ZIP não traz os arquivos de dados para evitar apagar registros existentes. Faça backup e preserve os arquivos de dados atuais. Se não existirem, o servidor aceita iniciar sem eles e os cria ao gravar novos dados.
- O endpoint /healthz deve retornar {"ok":true,"service":"EB Manager",...} quando o servidor estiver ativo.
- Neste ambiente, foram verificados: sintaxe do server.js, sintaxe do JavaScript inline do dashboard, JSONs, inicialização do servidor, rota de login e fluxo de verificação/promoção usando APIs Roblox simuladas. Não foi possível validar uma alteração real no grupo Roblox sem a chave Open Cloud do dono e permissões reais.
- Para aceitar pessoas, o painel consulta solicitações de entrada do grupo selecionado pela Open Cloud. Isso não permite adicionar um usuário que não tenha pedido para entrar; aceite uma solicitação pendente ou peça para a pessoa solicitar entrada.

O pacote não contém segredos. Nunca comite a chave Open Cloud nem a chave da API CDP no GitHub.
